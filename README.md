# Trama

**Control de producción textil para iPad, Android y web: funciona sin internet y se sincroniza solo.**

Trama runs a garment manufacturer's floor: cut orders are assigned to plants against their
monthly capacity, plant, cut and shipment managers report progress, and the owner sees revenue
in production, capacity per plant and urgent shipments at a glance. The iPad and Android apps keep
everything on the device, so the floor keeps working with no internet; when a licence is connected,
changes sync through an encrypted cloud to every device and to the web app.

Trama started as the internal app of **Industrial Peña Balles (IPB)**. It was rebuilt from a
2016 UIKit/Storyboard app into SwiftUI and is now licensed to other textile companies.

## How it fits together

```
 iPad (Core Data) ─┐                          ┌─ Web app (browser, IndexedDB cache)
                  ├── HTTPS ── platform API ──┤
 Android (Room) ──┘    (Vercel)    │          └─ Admin portal (vendor)
                                   │
                         Neon Postgres (every record AES-256-GCM encrypted per company)
```

- **Offline-first.** The apps write to their local database first and queue every change in an
  outbox. When the network is back they push the queue, then pull everyone else's changes.
  They also sync on launch/foreground, 3 s after a change, every 30 s while open, and on demand.
- **Conflicts:** last writer wins per record; a rejected stale change adopts the server copy.
- **Encryption:** each company has its own data key (wrapped by a master key held only in Vercel);
  records and user profiles are stored as ciphertext. TLS in transit. Passwords use PBKDF2-SHA256,
  the same on server and devices, so synced users can sign in offline.
- **Licences:** the admin portal creates a company with a plan, a term and limits (users, devices,
  plants). Its administrator receives an invitation email and signs in on the web or with
  «Conectar con mi licencia» on iPad/Android. Expired or suspended licences turn read-only.
- **Emails:** branded HTML emails (invitations, password resets, admin access, licence-request
  notification and the customer's confirmation in ES/EN/PT) share one layout:
  `platform/src/email-layout.ts` and its twin `contact-api/lib/email-layout.js`.

## Features

- **Cortes por asignar**: cut orders (code, list, garment, style, client, quantity, unit price, internal and client dates) with assignment progress.
- **Asignación por capacidad**: split a cut across plants; each plant previews its monthly capacity (MXN) live before you confirm.
- **Tablero de corte**: drag-and-drop kanban of cutting status (en espera → en mesa de corte → listo para confeccionar).
- **Reportes de producción**: plant, cut and shipment reports, a production funnel per cut, totals, filters and CSV export.
- **Envíos urgentes**, **calendario de plantas**, **dashboard** with KPIs, capacity and revenue charts.
- **Catálogos**: plants, clients and suppliers with contacts, a style photo gallery, projects/quotes, users.
- **Roles**: Administrador, Gerente de Cortes, Gerente de Planta (sees only their plant), Gerente de Envíos — enforced in the apps and on the server.
- **Calculadora** de producción, ⌘K search, light/dark mode, JSON backup/restore, optional import from the legacy IPB server.

## Getting started

**iOS** (Xcode 16+, `brew install xcodegen`):

```bash
cd ios && xcodegen generate && open Trama.xcodeproj
```

The first launch offers to create the company's admin account, load demo data, or connect a licence.
Demo accounts use the password `trama123`: `admin@`, `cortes@`, `planta@`, `envios@demo.local`.

**Android:** `cd android && ./gradlew :app:installDebug` (see [android/README.md](android/README.md)).

**Platform** (API + web app + admin portal):

```bash
cd platform
npm install
cp .env.example .env        # DATABASE_URL, MASTER_KEY, JWT_SECRET, APP_URL, GMAIL_*
npm run migrate
npm run create-admin -- you@example.com "Your Name"   # emails a link to set the password
npm run dev:api & npm run dev:web
```

**Website:** `python3 web/build.py && python3 -m http.server -d web/public 8000`.

## Deploys

- **Website:** CI on pushes to `main` (`.github/workflows/deploy-web.yml`) or `web/deploy.sh`.
- **Platform** and **contact API:** Vercel projects `trama-app` (root `platform/`, domain
  `trama-platform.vercel.app`) and `trama-contact-api` (root `contact-api/`), deployed from `main`.
- **Database:** Neon project `trama`. Run `npm run migrate` from `platform/` after schema changes.
- **iPad / Android:** built and distributed privately by the owner.
